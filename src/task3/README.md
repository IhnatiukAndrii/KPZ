# Завдання 3: Одинак (Singleton)

Цей проєкт демонструє використання патерну **Singleton** на прикладі класу `Authenticator`. Конструктор класу закрито від викликів іззовні, що гарантує наявність лише одного екземпляра під час роботи програми.

## Як запустити
Для запуску скрипта (із кореня проєкту) виконайте команду:
```bash
npx tsx src/task3/index.ts
```

## Приклад виконання
```text
true
```
*(Повернення `true` під час порівняння двох екземплярів доводить, що це один і той самий об'єкт).*
