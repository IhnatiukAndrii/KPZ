# Завдання 2: Декоратор (Decorator)

Цей проєкт демонструє використання патерну **Decorator** для динамічного розширення можливостей базових героїв RPG (`Warrior`, `Mage`, `Palladin`) різними предметами інвентарю (`Clothing`, `Weapon`, `Artifact`).

## Як запустити
Для запуску скрипта перейдіть у каталог завдання та виконайте:
```bash
cd task2
npm start
```

## Приклад виконання
```text
> task2@1.0.0 start
> tsc && node dist/index.js

--- Warrior Output ---
Warrior in fancy clothes with a sharp weapon with a sharp weapon
Total Power: 210

--- Mage Output ---
Mage in fancy clothes wielding an ancient artifact wielding an ancient artifact
Total Power: 140

--- Palladin Output ---
Palladin with a sharp weapon wielding an ancient artifact
Total Power: 165
```
