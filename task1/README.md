# Завдання 1: Адаптер (Adapter)

Цей проєкт демонструє використання патерну **Adapter** для створення уніфікованого інтерфейсу логування. Було реалізовано адаптер (`FileLoggerAdapter`), який дозволяє використовувати клас `FileWriter` під виглядом стандартного інтерфейсу логера (`ILogger`), так само як і базовий консольний логер.

## Як запустити
Для запуску скрипта перейдіть у каталог завдання та виконайте:
```bash
cd task1
npm start
```

## Приклад виконання
```text
> task1@1.0.0 start
> tsc && node dist/index.js

Console log message
Console warning message
Console error message
```
*(В консолі повідомлення виводяться зеленим, жовтим та червоним кольорами відповідно)*
